# Axiom Trading Journal

A free web-based trading journal for Forex and financial traders. Log trades, automatically calculate Pips, Risk-to-Reward Ratio, and P&L, track your trading psychology, and analyze your performance — all in one place.

🌐 **Live Website:** https://myaxiomjournal.com/

## Features

- Trade data entry with automatic Pip, Risk-to-Reward, P&L, and hold-time calculations
- Multi-account support (Main, Demo, Live, etc.)
- Equity curve chart and performance analytics
- Dashboard widgets: Win Rate, Average R:R, Best/Worst Pair
- Position size calculator
- Excel/CSV and JSON export
- Screenshot attachments per trade
- Search and filter past entries

## Tech Stack

- **Frontend:** HTML, CSS, Vanilla JavaScript — hosted on GitHub Pages
- **Backend:** Node/Express — hosted on Render
- **Database:** PostgreSQL (Neon)
